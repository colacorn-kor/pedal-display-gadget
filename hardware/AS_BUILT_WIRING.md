# GG 실물 브레드보드 배선표 (As-Built)

> **소유자:** 태윤
>
> 이 문서는 지금 책상 위에 존재하는 **실물 회로의 SSOT**다. 제안 회로와 목표 회로를
> 추측해서 섞지 않는다. 태윤이 직접 수정하거나, 태윤이 물리 변경을 명시적으로 보고한
> 경우에만 Codex가 그 사실과 날짜를 반영한다. 과거 배선은 문서 뒤에 누적하지 않고 Git
> 이력으로 확인한다.

## 기록 기준

- 갱신일: 2026-08-05
- 기본 전원 상태: 외부 9V 분리, USB 연결
- `완료`: 태윤의 조립·동작 보고가 있는 연결
- `배선 완료/기능 미확인`: 물리 연결 보고는 있으나 해당 기능을 아직 실행하지 않음
- `미확인`: 현재 실물의 정확한 끝점을 다시 확인해야 함
- `미연결`: 실물에 연결하지 않음

## 7. 오디오 입력과 Thru

이 영역은 2026-08-05 현재 재배선 대상이다. 실물에서 직접 확인하기 전에는 제안 회로의
연결을 복사하지 않는다.

| 연결 | 상태 | 실물 확인 뒤 기록할 내용 |
|---|---|---|
| 입력잭 Tip ↔ 출력잭 Tip | 미확인 | 직결 여부 |
| 두 잭 Sleeve ↔ GND | 미확인 | 공통 GND 여부 |
| 입력잭 Tip → 분석 탭 | 미확인 | 실제 커플링 부품과 끝점 |
| TL072 pin 1 → PCM1808 `VINL` | 미확인 | 실제 커플링 부품과 끝점 |
| PCM1808 `VINR` | 미확인 | 연결 유무 |
| LINE/INST SPDT | 미확인 | 현재 연결 유무와 방향 |

## 9. 시각 보조 자료

- Fritzing 파일 위치: `hardware/as-built/GG_PROTOTYPE.fzz`
- Fritzing은 부품 위치·브레드보드 구멍·점퍼 색을 확인하는 보조 도면이다.
- Fritzing과 이 문서가 다르면 **이 문서의 연결표를 먼저 실제 회로와 대조**하고 둘을 함께
  바로잡는다. 확인 전에는 어느 쪽도 추측으로 맞았다고 처리하지 않는다.
