# GG As-Built 시각 자료

이 폴더에는 태윤이 보는 실물 브레드보드 보조 자료를 둔다.

| 파일 | 역할 |
|---|---|
| `GG_PROTOTYPE.fzz` | Fritzing Breadboard View. 실제 부품 위치·구멍·점퍼 색 기록 |
| `photos/` | 필요할 때 위·옆면 사진 보관 |

전기적 연결의 현재 SSOT는 `../AS_BUILT_WIRING.md`다. Fritzing에 정확한 모듈 부품이
없으면 같은 핀 수의 범용 헤더를 쓰고 `ST7796`, `PCM1808`, `SZH-EKBZ-005`와 핀 이름을
명시한다. 부품 그림 제작 때문에 실물 기록을 미루지 않는다.

실물 배선을 바꿀 때는 Fritzing과 `AS_BUILT_WIRING.md`를 같은 변경으로 갱신한다. 과거
도면 사본은 이 폴더에 누적하지 않고 Git 이력으로 확인한다.
